# Arena Battle

ブラウザで動く 3D アリーナ対戦アクションゲーム（Three.js / TypeScript / Vite）。

現在は **Phase 1（キャラクターの土台とアリーナ）** の開発中です。

## 必要なもの

- Node.js 22.12 以上（LTS 推奨）

## 使い方

```bash
npm install       # 初回・更新後
npm run dev       # 開発サーバー（同じ Wi-Fi のスマホからも開けます）
npm run build     # 型チェック + 本番ビルド（dist/）
npm run preview   # 本番ビルドの確認
npm test          # 単体テスト
npm run typecheck # 型チェックのみ
```

Windows PC で起動してスマートフォンから確認する手順は
[docs/LOCAL_TESTING_WINDOWS.md](docs/LOCAL_TESTING_WINDOWS.md) を参照してください。

### 開発サーバーの公開範囲（重要）

- `npm run dev` / `npm run preview` は、スマホでの確認のため **同じ Wi-Fi（同じネットワーク）の端末からアクセスできる**設定です（`vite.config.ts` の `host: true`）。
- **信頼できるプライベートネットワークでのみ使用してください。** 公共の Wi-Fi では起動しないでください。
- **動作確認が終わったら開発サーバーを停止してください**（`Ctrl` + `C`）。
- これは **インターネットに公開するための設定ではありません**。ポート開放などで外部に公開しないでください。

### URL パラメータ

| パラメータ | 内容 |
|---|---|
| `?quality=high` / `medium` / `low` / `0`〜`9` | 画質の段階（0が最高）。指定しなければ「中」（段階3） |
| `?fps=30` | 30fps モード |
| `?stats=0` | 統計表示を消す |
| `?debug=1` | 本番ビルドでも開発パネルを表示する |
| `?view=front` / `oblique` / `top` / `close` | 確認用カメラの視点（正面の全景・斜めの全景・上空の全景・戦闘エリアの近景） |
| `?scale=0` | 大きさの目安（1.8m の人形）を隠す |

## フォルダ構成（A2-1 時点）

```
src/
  main.ts                 起動処理（WebGL2 の確認・開発パネルの読み込み・URL パラメータ）
  core/                   全体の組み立て（Game）、固定60Hzのループ、再現性のある乱数
  platform/               画質（手動切り替えのみ）、画面サイズとピクセル倍率、WebGL2の確認
  render/                 描画パイプライン、HDR/MSAAのフォールバック、コンテキスト喪失時のGPU資源の解放、影、
                          シェーダーのエラー検出、描画能力の確認、ノイズ画像
  render/internal/        three.js の内部実装に依存する処理（フレームバッファ検査・シェーダーの差し込み）
  stage/                  ステージの共通の約束事と管理（StageDefinition / StageManager）
  stage/stages/colosseum/ Dusk Colosseum（寸法・色・床のシェーダー・照明・組み立て）
  debug/                  確認用カメラ（開発専用）、大きさの目安、統計表示、開発パネル
tests/                    Vitest の単体テスト
docs/                     手順書・設計の決定事項
```

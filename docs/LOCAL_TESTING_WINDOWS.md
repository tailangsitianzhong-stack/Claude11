# Windows PC で起動し、スマートフォンから確認する手順

この手順書では、次の3つを順番に説明します。

1. Windows PC にゲームを準備して起動する
2. PC のブラウザで確認する
3. 同じ Wi-Fi につないだ iPhone / Android から確認する

所要時間の目安：初回 20〜30分、2回目以降 1〜2分

> ### ⚠ 開発サーバーの公開範囲について（必ずお読みください）
>
> - `npm run dev` で起動した開発サーバーは、スマートフォンから確認できるように
>   **同じ Wi-Fi（同じネットワーク）につながっている端末なら、どの端末からでも開ける**設定になっています。
> - **自宅など、信頼できるプライベートなネットワークでだけ使ってください。**
>   カフェ・ホテル・駅などの公共の Wi-Fi では起動しないでください。
> - **動作確認が終わったら、必ず開発サーバーを停止してください**（PowerShell の画面で `Ctrl` + `C`）。
> - これは開発中の確認用の設定で、**インターネットに公開するための設定ではありません**。
>   ルーターのポート開放などを行って外部から接続できるようにしないでください。

## 1. 最初に1回だけ行う準備

### 1-1. Node.js をインストールする

ゲームを動かすための土台となるソフトです。

1. ブラウザで <https://nodejs.org/ja> を開きます。
2. **「LTS」と書かれた版**（推奨版）の Windows 用インストーラー（`.msi`）をダウンロードします。
   - バージョン **22.12 以上**が必要です（24 系でも問題ありません）。
3. ダウンロードしたファイルを開き、表示される内容のまま「Next」を押して進めます。
   - 途中の「Tools for Native Modules」のチェックは不要です（付けなくて大丈夫です）。
4. インストールが終わったら、確認します。
   - スタートメニューで「PowerShell」と入力して **Windows PowerShell** を開きます。
   - 次のように入力して Enter を押します。

     ```powershell
     node -v
     ```

   - `v22.12.0` 以上（例：`v22.20.0`、`v24.11.0`）と表示されれば成功です。
   - 「認識されません」と表示された場合は、PowerShell をいったん閉じて開き直してください。

### 1-2. Git をインストールする

ゲームのファイルを GitHub から取得・更新するためのソフトです。

1. <https://git-scm.com/download/win> を開き、インストーラーをダウンロードします。
2. インストーラーを開き、設定は変更せずに「Next」で進めて完了させます。
3. PowerShell を開き直して、次を入力します。

   ```powershell
   git --version
   ```

   `git version 2.xx.x` のように表示されれば成功です。

### 1-3. ゲームのファイルを取得する

PowerShell で次を1行ずつ入力します。
（`Documents` フォルダーの中に `Claude11` フォルダーが作られます）

```powershell
cd $HOME\Documents
git clone https://github.com/tailangsitianzhong-stack/Claude11.git
cd Claude11
git checkout claude/3d-arena-battle-design-ky0xbb
```

- リポジトリが非公開の場合、初回に GitHub へのログイン画面が表示されます。ブラウザでログインして許可してください。

### 1-4. 必要な部品をインストールする

```powershell
npm install
```

- 1〜3分ほどかかります。最後に `found 0 vulnerabilities` などと表示されれば完了です。
- `npm WARN` という表示が出ても、エラー（`npm ERR!`）でなければ問題ありません。

## 2. ゲームを起動する（毎回）

1. PowerShell を開き、ゲームのフォルダーへ移動します。

   ```powershell
   cd $HOME\Documents\Claude11
   ```

2. **最新の状態に更新します**（チェックポイントごとに新しい内容が追加されるため）。

   ```powershell
   git pull
   npm install
   ```

3. 起動します。

   ```powershell
   npm run dev
   ```

4. 次のような表示が出たら起動成功です。

   ```
     VITE v8.x.x  ready in 300 ms

     ➜  Local:   http://localhost:5173/
     ➜  Network: http://192.168.1.23:5173/
   ```

   - **`Network:` の行のアドレスが、スマートフォンから開くアドレスです**（数字は環境によって違います）。
   - 確認している間は、この PowerShell の画面を閉じないでください。閉じるとゲームも停止します。
   - 停止するときは、PowerShell の画面で `Ctrl` + `C` を押します。

5. **初回だけ**、次のような「Windows セキュリティの重要な警告」（ファイアウォール）が表示されることがあります。
   - **「プライベート ネットワーク」にだけチェック**を入れて「アクセスを許可する」を押してください。
   - 「パブリック ネットワーク」にはチェックを入れないでください（公共の Wi-Fi で他人から接続されるのを防ぐため）。
   - これを許可しないと、スマートフォンからアクセスできません。

## 3. PC のブラウザで確認する

Chrome または Edge で <http://localhost:5173/> を開きます。

- 画面右上の「開発パネル」で、画質の段階やフレームレートを切り替えられます。
- 画面左上には FPS・描画コール数・画質の状態が表示されます。
  - 起動直後や画質を変えた直後は「FPS 計測準備中」と表示されます（シェーダーの準備などで遅いフレームを統計に混ぜないため）。
  - 起動にかかった時間は「起動 ◯s（初回フレーム ◯ms）」として別に表示されます。
- チェックポイント A1 の段階では、仮のシーン（床・柱・箱）が表示され、マウスのドラッグで視点を回せます。

## 4. IP アドレスを確認する（`Network:` が表示されない・複数ある場合）

1. PowerShell をもう1つ開き、次を入力します。

   ```powershell
   ipconfig
   ```

2. 「**Wireless LAN adapter Wi-Fi**」（有線接続の場合は「イーサネット アダプター」）の項目にある
   「**IPv4 アドレス**」を探します。

   ```
   Wireless LAN adapter Wi-Fi:
      IPv4 アドレス . . . . . . . . . . . .: 192.168.1.23
   ```

3. この数字（例：`192.168.1.23`）がスマートフォンから開くアドレスになります。
   - 通常は `192.168.` / `10.` / `172.16.`〜`172.31.` で始まります。
   - `vEthernet` や `VirtualBox` など、仮想的なアダプターのアドレスは使いません。

## 5. スマートフォンから開く

### 共通の準備

- スマートフォンを **PC と同じ Wi-Fi** に接続します（モバイルデータ通信ではつながりません）。
- VPN アプリを使っている場合は、一時的にオフにします。

### iPhone（Safari）

1. Safari を開きます。
2. アドレスバーに **`http://192.168.1.23:5173/`** のように入力します（数字は手順4で確認したもの）。
   - 先頭の `http://` と、末尾の `:5173` を省略しないでください。
3. ゲームの画面が表示されれば成功です。
4. （推奨）画面を横向きにして確認します。

### Android（Chrome）

1. Chrome を開きます。
2. アドレスバーに **`http://192.168.1.23:5173/`** のように入力します。
3. ゲームの画面が表示されれば成功です。

### 確認中に便利なアドレスの付け足し

アドレスの最後に次を付けると、表示を切り替えられます。

| 付け足す文字 | 内容 |
|---|---|
| `?quality=high` / `?quality=medium` / `?quality=low` | 画質を 高 / 中 / 低 に固定して開く |
| `?quality=0` 〜 `?quality=9` | 画質の段階を数字で指定する |
| `?fps=30` | 30fps モードで開く |
| `?stats=0` | 左上の統計表示を消す |

- 何も付けない場合は、PC・スマホとも画質「中」（段階3）・60fps で始まります。
- 画質の設定は保存されません（再読み込みすると初期値に戻ります）。保存の機能はチェックポイントD で追加します。

例：`http://192.168.1.23:5173/?quality=low&fps=30`

## 6. つながらないときの確認項目

| 症状 | 確認すること |
|---|---|
| スマホで「サーバーに接続できません」 | ① PC とスマホが同じ Wi-Fi か ② PowerShell で `npm run dev` が動いたままか ③ アドレスの `http://` と `:5173` が正しいか |
| 上を確認してもつながらない | Windows のネットワークが「パブリック」になっている可能性があります。**設定 → ネットワークとインターネット → Wi-Fi → 接続中のWi-Fi名 → ネットワーク プロファイルの種類** を「**プライベート ネットワーク**」に変更し、`npm run dev` を起動し直してください。 |
| それでもつながらない | ファイアウォールの許可が付いていない可能性があります。スタートメニューで PowerShell を**右クリック →「管理者として実行」**し、次の1行を入力してください（ポート5173をプライベートネットワークで許可します）。<br>`New-NetFirewallRule -DisplayName "Arena Battle dev (5173)" -Direction Inbound -Protocol TCP -LocalPort 5173 -Action Allow -Profile Private` |
| カフェ・ホテル・会社の Wi-Fi、ゲスト用 Wi-Fi | 端末同士の通信が禁止されている場合があります（「AP 分離」「プライバシーセパレーター」）。自宅の Wi-Fi を使うか、スマホのテザリングに PC をつないでお試しください。 |
| 画面が真っ白・「WebGL2 に対応していない」と表示される | iOS は 16.4 以上、Android の Chrome は最新版に更新してください。 |
| 表示が古いまま変わらない | `git pull` と `npm install` を実行してから `npm run dev` を起動し直し、スマホのブラウザで再読み込みしてください。 |

## 7. 本番用のビルドで確認する（任意）

開発用の起動（`npm run dev`）とは別に、公開時と同じ形で確認したい場合に使います。

```powershell
npm run build
npm run preview
```

- `Network: http://192.168.x.x:4173/` のアドレスで開きます（ポートは **4173**）。
- 開発パネルを表示したい場合は、アドレスの最後に `?debug=1` を付けます。
- ファイアウォールの手動設定が必要な場合は、上のコマンドの `5173` を `4173` に変えて実行してください。
